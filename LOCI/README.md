# LOCI project page

Static project page for **LOCI: Spatial Linear Memory for Streaming World Models**.

Intended URL: https://xiaji2021.github.io/LOCI/

This website is separate from the code repository. To keep the intended URL, publish this directory under `LOCI/` in `xiaji2021/xiaji2021.github.io`, preserving any existing personal-site files. Publishing a separate repository named `LOCI-page` would instead produce `/LOCI-page/`.

All page assets are local; no build step or external fonts are required. Keep `.nojekyll` at the publishing source root if using branch-based Pages deployment.

Local preview: `python -m http.server 8080` from this directory.
