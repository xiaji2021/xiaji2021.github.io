What it keeps.

Two kinds of memory work together. A recurrent state takes in every frame and stays the same size, however long the stream runs. Beside it, a bounded set of retained frames keeps sharp detail of the views that cover the scene best.

  • Sink frameThe first view. Always kept.
    1
  • AnchorsEarly views, pinned and never dropped.
    0
  • Coverage bankOlder views chosen to cover the scene, up to 20.
    0
  • Recent windowThe last 8 frames, for smooth motion.
    0
  • Recurrent stateKDA layers fold every frame into a fixed-size state, read through camera geometry.
    0
