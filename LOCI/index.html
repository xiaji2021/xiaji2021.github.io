Long-range recall

A familiar place.
A remembered world.

Given a recorded history, LOCI continues along the camera path and recovers previously observed content.

The idea

Remember what you saw.
Retrieve what you need.

When a camera revisits a previously observed region, a video world model should reproduce what was there before. LOCI combines a compact recurrent memory with a cache of visual observations, using projective camera geometry to guide memory reads and writes.

01

Spatial recurrent memory

Camera geometry enters both memory addressing and stored content in the recurrent linear-attention blocks.

02

Retained visual detail

Cache-backed attention blocks retain past observations and read them using scene context accumulated by recurrent memory.

03

Bounded streaming

A bounded bank of retained observations supports long rollouts at constant memory, alongside recurrent state that summarises history.
